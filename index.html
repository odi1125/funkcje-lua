Dokumentacja Funkcji Lua i Roblox

1. Podstawowe Funkcje

print()

Opis: Funkcja print() wyświetla tekst lub wartość w konsoli.

print("Witaj, świecie!")

Wynik: Witaj, świecie!

tonumber()

Opis: Funkcja tonumber() konwertuje tekst na liczbę.

tonumber("123")

Wynik: 123

tostring()

Opis: Funkcja tostring() konwertuje wartość na tekst.

tostring(123)

Wynik: "123"

type()

Opis: Funkcja type() zwraca typ wartości (np. `string`, `table`, `number`).

print(type("tekst"))
print(type(123))
print(type({}))

Wynik: string, number, table

pairs()

Opis: Funkcja pairs() iteruje po parach klucz-wartość w tabeli.

local t = {a = 1, b = 2, c = 3}
for k, v in pairs(t) do
    print(k, v)
end

Wynik: a 1
b 2
c 3

ipairs()

Opis: Funkcja ipairs() iteruje po tabeli numerowanej, od pierwszego indeksu.

local t = {1, 2, 3}
for i, v in ipairs(t) do
    print(i, v)
end

Wynik: 1 1
2 2
3 3

next()

Opis: Funkcja next() zwraca następny klucz i wartość w tabeli.

local t = {a = 1, b = 2}
local k, v = next(t)
print(k, v)  -- może zwrócić "a 1"

Wynik: może zwrócić "a 1" lub inną parę.

2. Matematyczne Funkcje

math.abs()

Opis: Funkcja math.abs() zwraca wartość bezwzględną liczby.

math.abs(-5)

Wynik: 5

math.cos()

Opis: Funkcja math.cos() oblicza cosinus kąta (w radianach).

math.cos(math.pi / 2)

Wynik: 0

math.random()

Opis: Funkcja math.random() generuje losową liczbę.

math.random(1, 10)

Wynik: Losowa liczba z zakresu 1-10

3. Funkcje Tabel

table.insert()

Opis: Funkcja table.insert() wstawia element do tabeli.

local tab = {1, 2, 3}
table.insert(tab, 4)
for i, v in ipairs(tab) do
    print(i, v)
end

Wynik: 1 1
2 2
3 3
4 4

table.remove()

Opis: Funkcja table.remove() usuwa element z tabeli.

local tab = {1, 2, 3}
table.remove(tab, 2)
for i, v in ipairs(tab) do
    print(i, v)
end

Wynik: 1 1
3 3

table.sort()

Opis: Funkcja table.sort() sortuje tabelę.

local tab = {3, 1, 2}
table.sort(tab)
for i, v in ipairs(tab) do
    print(i, v)
end

Wynik: 1 1
2 2
3 3
