Dokumentacja Funkcji Lua i Roblox

1. Podstawowe Funkcje

print()

Opis: Funkcja print() wyświetla tekst lub wartość w konsoli.

print("Witaj, świecie!")

Wynik: Witaj, świecie!

tonumber()

Opis: Funkcja tonumber() konwertuje tekst na liczbę.

tonumber("123")

Wynik: 123

tostring()

Opis: Funkcja tostring() konwertuje wartość na tekst.

tostring(123)

Wynik: "123"

type()

Opis: Funkcja type() zwraca typ wartości (np. `string`, `table`, `number`).

print(type("tekst"))
print(type(123))
print(type({}))

Wynik: string, number, table

pairs()

Opis: Funkcja pairs() iteruje po parach klucz-wartość w tabeli.

local t = {a = 1, b = 2, c = 3}
for k, v in pairs(t) do
    print(k, v)
end

Wynik: a 1
b 2
c 3

ipairs()

Opis: Funkcja ipairs() iteruje po tabeli numerowanej, od pierwszego indeksu.

local t = {1, 2, 3}
for i, v in ipairs(t) do
    print(i, v)
end

Wynik: 1 1
2 2
3 3

next()

Opis: Funkcja next() zwraca następny klucz i wartość w tabeli.

local t = {a = 1, b = 2}
local k, v = next(t)
print(k, v)  -- może zwrócić "a 1"

Wynik: może zwrócić "a 1" lub inną parę.

2. DataStore

DataStoreService

Opis: DataStoreService to usługa w Robloxie, która umożliwia przechowywanie danych graczy, które przetrwają po zakończeniu gry.

local DataStoreService = game:GetService("DataStoreService")
local playerDataStore = DataStoreService:GetDataStore("PlayerDataStore")

-- Zapis danych gracza
local function savePlayerData(player)
    local playerId = player.UserId
    local success, errorMessage = pcall(function()
        playerDataStore:SetAsync(playerId, player.Points)
    end)
    if success then
        print("Dane gracza zapisane!")
    else
        warn("Błąd podczas zapisywania danych: " .. errorMessage)
    end
end

-- Zdarzenie, gdy gracz opuszcza grę
game.Players.PlayerRemoving:Connect(function(player)
    savePlayerData(player)
end)

3. Animacje GUI

TweenService

Opis: TweenService pozwala na tworzenie animacji dla GUI w Robloxie (np. animowanie pozycji, rozmiaru, koloru itp.).

local TweenService = game:GetService("TweenService")
local frame = script.Parent -- Załóżmy, że to jest obiekt Frame
local goalPosition = UDim2.new(0.5, -50, 0.5, -50) -- Pozycja docelowa

local tweenInfo = TweenInfo.new(2, Enum.EasingStyle.Quad, Enum.EasingDirection.Out)
local goal = {Position = goalPosition}
local tween = TweenService:Create(frame, tweenInfo, goal)

tween:Play()

4. Zarządzanie Graczami

game.Players.PlayerAdded:Connect(function(player)

game.Players.PlayerRemoving

game.Players.PlayerRemoving:Connect(function(player)
