Dokumentacja Funkcji Lua i Roblox

Podstawowe Funkcje

print()

Opis: Funkcja print() wyświetla tekst lub wartość w konsoli.

print("Witaj, świecie!")

Wynik: Witaj, świecie!

tonumber()

Opis: Funkcja tonumber() konwertuje tekst na liczbę.

tonumber("123")

Wynik: 123

type()

Opis: Funkcja type() zwraca typ obiektu (np. string, table, number).

print(type("tekst"))
print(type(123))
print(type({}))

Wynik: string, number, table

DataStoreService

DataStoreService

Opis: DataStoreService to usługa w Roblox, która pozwala na przechowywanie danych, które przetrwają po zakończeniu gry.

local DataStoreService = game:GetService("DataStoreService")
local playerDataStore = DataStoreService:GetDataStore("PlayerDataStore")

-- Zapis danych gracza
local function savePlayerData(player)
    local playerId = player.UserId
    local success, errorMessage = pcall(function()
        playerDataStore:SetAsync(playerId, player.Points)
    end)
    if success then
        print("Dane gracza zapisane!")
    else
        warn("Błąd podczas zapisywania danych: " .. errorMessage)
    end
end

Animacje

Animator

Opis: Animator pozwala na odtwarzanie animacji na postaciach. Animacje są kontrolowane przez komponent Animator w postaci Humanoid.

local animation = Instance.new("Animation")
animation.AnimationId = "rbxassetid://ANIMATION_ID"  -- Zastąp ANIMATION_ID rzeczywistym ID animacji

local humanoid = game.Workspace.Player.Character:WaitForChild("Humanoid")
local animator = humanoid:WaitForChild("Animator")
local animTrack = animator:LoadAnimation(animation)

animTrack:Play()

Animacje GUI

TweenService

Opis: TweenService umożliwia tworzenie animacji dla obiektów GUI, takich jak zmiana pozycji, rozmiaru, przezroczystości, kolorów i innych właściwości.

local TweenService = game:GetService("TweenService")
local frame = script.Parent -- Załóżmy, że to jest obiekt Frame
local goalPosition = UDim2.new(0.5, -50, 0.5, -50) -- Pozycja docelowa

local tweenInfo = TweenInfo.new(2, Enum.EasingStyle.Quad, Enum.EasingDirection.Out)
local goal = {Position = goalPosition}
local tween = TweenService:Create(frame, tweenInfo, goal)

tween:Play()

Funkcje na Tabelach

table.insert()

Opis: Funkcja table.insert() wstawia element do tabeli na określoną pozycję.

local tab = {1, 2, 3}
table.insert(tab, 4)
for i, v in ipairs(tab) do
  print(i, v)
end

Wynik: 1 1
2 2
3 3
4 4

table.remove()

Opis: Funkcja table.remove() usuwa element z tabeli.

local tab = {1, 2, 3}
table.remove(tab, 2)
for i, v in ipairs(tab) do
  print(i, v)
end

Wynik: 1 1
3 3

table.sort()

Opis: Funkcja table.sort() sortuje tabelę.

local tab = {3, 1, 2}
table.sort(tab)
for i, v in ipairs(tab) do
  print(i, v)
end

Wynik: 1 1
2 2
3 3
