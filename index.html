Dokumentacja Funkcji Lua

Podstawowe Funkcje

print()

Opis: Funkcja print() wyświetla tekst lub wartość w konsoli.

print("Witaj, świecie!")

Wynik: Witaj, świecie!

tonumber()

Opis: Funkcja tonumber() konwertuje tekst na liczbę.

tonumber("123")

Wynik: 123

type()

Opis: Funkcja type() zwraca typ obiektu (np. string, table, number).

print(type("tekst"))
print(type(123))
print(type({}))

Wynik: string, number, table

Funkcje Matematyczne

math.random()

Opis: Funkcja math.random() generuje losową liczbę.

math.random(1, 10)

Wynik: Losowa liczba z zakresu 1-10 (np. 7)

math.sin()

Opis: Funkcja math.sin() oblicza sinus kąta (w radianach).

math.sin(math.pi / 2)

Wynik: 1

math.floor()

Opis: Funkcja math.floor() zaokrągla liczbę w dół do najbliższej liczby całkowitej.

math.floor(5.7)

Wynik: 5

Funkcje na Tabelach

table.insert()

Opis: Funkcja table.insert() wstawia element do tabeli na określoną pozycję.

local tab = {1, 2, 3}
table.insert(tab, 4)
for i, v in ipairs(tab) do
  print(i, v)
end

Wynik: 1 1
2 2
3 3
4 4

table.remove()

Opis: Funkcja table.remove() usuwa element z tabeli.

local tab = {1, 2, 3}
table.remove(tab, 2)
for i, v in ipairs(tab) do
  print(i, v)
end

Wynik: 1 1
3 3

table.sort()

Opis: Funkcja table.sort() sortuje tabelę.

local tab = {3, 1, 2}
table.sort(tab)
for i, v in ipairs(tab) do
  print(i, v)
end

Wynik: 1 1
2 2
3 3

Funkcje na Ciągach Znaków

string.len()

Opis: Funkcja string.len() zwraca długość ciągu znaków.

string.len("Hello")

Wynik: 5

string.sub()

Opis: Funkcja string.sub() zwraca fragment ciągu znaków.

string.sub("Lua Programming", 1, 3)

Wynik: Lua

string.upper()

Opis: Funkcja string.upper() konwertuje wszystkie litery ciągu na wielkie litery.

string.upper("lua")

Wynik: LUA

string.lower()

Opis: Funkcja string.lower() konwertuje wszystkie litery ciągu na małe litery.

string.lower("LUA")

Wynik: lua
