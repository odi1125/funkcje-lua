Dokumentacja Funkcji Lua i Roblox

1. Podstawowe Funkcje Lua

print()

Opis: Wyświetla tekst lub wartość w konsoli.

print("Hello, World!")

Wynik: Witaj, świecie!

local

Opis: zapisuje daną wartość 

          local x = "Hello Wordl"
          print(x)

Wynik: Witaj, świecie!

globalna

Opis: zapisuje daną wartość gdzie możesz ją wszędzie wykorzystać 

          x = "Hello Wordl"
          print(x)

Wynik: Witaj, świecie!

tonumber()

Opis: Konwertuje tekst na liczbę.

tonumber("123")

Wynik: 123

tostring()

Opis: Konwertuje wartość na tekst.

tostring(123)

Wynik: "123"

type()

Opis: Zwraca typ wartości (np. string, table, number).

print(type("tekst"))
print(type(123))
print(type({}))

Wynik: string, number, table

2. Matematyczne Funkcje Lua

math.abs()

Opis: Zwraca wartość bezwzględną liczby.

math.abs(-5)

Wynik: 5

math.random()

Opis: Generuje losową liczbę.

math.random(1, 10)

Wynik: Losowa liczba z zakresu 1-10

math.cos()

Opis: Zwraca cosinus kąta (w radianach).

math.cos(math.pi / 2)

Wynik: 0

3. Pętle i Instrukcje Warunkowe Lua

if

Opis: Instrukcja warunkowa, która sprawdza, czy warunek jest prawdziwy, a jeśli tak, wykonuje blok kodu.

if x > 10 then
    print("x jest większe niż 10")
end

Wynik: Jeśli x > 10, wyświetli komunikat.

else

Opis: Instrukcja używana z `if` do wykonania alternatywnego bloku kodu, jeśli warunek w `if` jest fałszywy.

if x > 10 then
    print("x jest większe niż 10")
else
    print("x jest mniejsze lub równe 10")
end

elseif

Opis: Używane do sprawdzenia dodatkowego warunku, jeśli poprzedni warunek w `if` był fałszywy.

if x > 10 then
    print("x jest większe niż 10")
elseif x == 10 then
    print("x jest równe 10")
else
    print("x jest mniejsze niż 10")
end

while

Opis: Pętla wykonująca blok kodu dopóki warunek jest prawdziwy.

local x = 0
while x < 5 do
    print(x)
    x = x + 1
end

for

Opis: Pętla wykonująca blok kodu określoną liczbę razy.

for i = 1, 5 do
    print(i)
end

repeat

Opis: Pętla wykonująca blok kodu przynajmniej raz, a potem sprawdzająca warunek.

local x = 0
repeat
    print(x)
    x = x + 1
until x >= 5

4. DataStore w Robloxie

DataStoreService

Opis: DataStore umożliwia przechowywanie danych graczy w Robloxie, które przetrwają po zakończeniu gry.

local DataStoreService = game:GetService("DataStoreService")
local playerDataStore = DataStoreService:GetDataStore("PlayerDataStore")

local function savePlayerData(player)
    local playerId = player.UserId
    local success, errorMessage = pcall(function()
        playerDataStore:SetAsync(playerId, player.Points)
    end)
    if success then
        print("Dane gracza zapisane!")
    else
        warn("Błąd podczas zapisywania danych: " .. errorMessage)
    end
end

game.Players.PlayerRemoving:Connect(function(player)
    savePlayerData(player)
end)

5. Animacje GUI w Robloxie

TweenService

Opis: TweenService pozwala na animowanie elementów GUI w Robloxie.

local TweenService = game:GetService("TweenService")
local frame = script.Parent -- Załóżmy, że to jest obiekt Frame
local goalPosition = UDim2.new(0.5, -50, 0.5, -50) -- Pozycja docelowa

local tweenInfo = TweenInfo.new(2, Enum.EasingStyle.Quad, Enum.EasingDirection.Out)
local goal = {Position = goalPosition}
local tween = TweenService:Create(frame, tweenInfo, goal)

tween:Play()

6. Zarządzanie Graczami w Robloxie

game.Players.PlayerAdded

Opis: Zdarzenie uruchamiane, gdy gracz dołącza do gry.

game.Players.PlayerAdded:Connect(function(player)
    print(player.Name .. " dołączył do gry!")
end)

game.Players.PlayerRemoving

Opis: Zdarzenie uruchamiane, gdy gracz opuszcza grę.

game.Players.PlayerRemoving:Connect(function(player)
    print(player.Name .. " opuścił grę!")
end)
